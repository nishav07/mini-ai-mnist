# mini-ai-mnist (PyTorch)

A minimal, fully working PyTorch project that trains a small CNN on MNIST (handwritten digits).  
You can run it directly from VS Code (launch configs included) or via the terminal.

## Quick Start

### 1) Create & activate a virtual environment (recommended)

```bash
# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# macOS/Linux
python3 -m venv .venv
source .venv/bin/activate
